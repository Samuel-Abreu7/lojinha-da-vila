Lojinha da Vila

Indicações de livros, jogos e materiais para adultos. Cada compra feita pelos nossos links ajuda a manter um projeto educativo sem anúncios e sem cobrança.

Como funciona

  • Este site não vende nada nem recebe pagamento. Cada indicação leva ao site da loja parceira, onde a compra é feita.
  • Os links são de afiliado: recebemos uma comissão se você comprar, sem custo a mais para você. Cada indicação diz isso.
  • As indicações são para adultos. Este site não é feito para crianças nem dirigido a elas.

Privacidade

  • Este site não tem cadastro, formulário, cookies próprios, contador de visitas nem rastreador. Nenhuma imagem ou script é carregado de outros sites.
  • Quando você toca numa indicação e vai para a loja parceira, as regras de privacidade passam a ser as dela, inclusive o cookie que registra a indicação.

Para onde vai o dinheiro

  • Primeiro, os custos deste site e do projeto educativo que ele apoia.
  • O que sobrar seria usado em benefício dos alunos de uma escola pública municipal, em itens indicados pelos professores.
  • Isso ainda é uma intenção: só será dito como certo aqui depois de combinado com a escola e a prefeitura. A prestação de contas será publicada aqui.
